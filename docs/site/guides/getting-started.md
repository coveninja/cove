# Getting started

Cove is a local-first media library and player for desktop, Android, and Android TV. You can use it without an account, and a new installation does not include third-party stream sources.

## 1. Install Cove

Use the [download center](https://cove.ninja/download) to choose the package for your device:

- [Linux](install/linux.md)
- [Windows](install/windows.md)
- [macOS](install/macos.md)
- [Android phones, tablets, and televisions](install/android-tv.md)

Only packages attached to the official GitHub release are Cove releases.

## 2. Complete first-run setup

On first launch Cove asks for a profile name and a few taste choices. Profiles keep libraries, watch progress, ratings, settings, and recommendations separate.

You can skip account sign-in. Local profiles work offline and remain on the device. Sign in only when you want [cross-device sync](accounts-and-sync.md).

## 3. Add titles and playback sources

Search and discovery use Cove's configured catalog metadata. Add a title to **My List** to track its status, rating, episodes, and progress.

Cove is a player and organizer, not a content host. Legal watch options appear where available. Any community addon or scraper source is optional and is your responsibility to review and use lawfully. See [Addons and sources](addons-and-sources.md).

## 4. Know where to get help

Start with [Troubleshooting](troubleshooting.md). When reporting a bug, include the Cove version, platform, installation method, reproduction steps, and logs if available.
